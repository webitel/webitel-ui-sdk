# `useObserveHeightUntilStable`

Добиває скрол у задану позицію, поки контент **асинхронно досаджується** — рендериться хедер,
довантажуються зображення/відео, і висота стрибає кількома хвилями. Викликає `callback` на кожну
зміну висоти `target` і зупиняється або за таймаутом, або на анмаунті.

На відміну від [`useScrollToBottomBtn`](./use-scroll-to-bottom-btn.md), цей композібл незалежний:
компонент створює його інстанцію(-ї) сам і сам вирішує, за яким елементом стежити й з яким
таймаутом.

## Input params

| Params     | Type                       | Description                                                                                     |
| ---------- | -------------------------- | --------------------------------------------------------------------------------------------- |
| `target`   | `Ref<HTMLElement \| null>` | Елемент, за ресайзом якого стежимо (контейнер або контент — залежно від кейсу).                |
| `callback` | `() => void`               | Викликається на кожну зміну висоти `target` (окрім часу viewport-переходу фуллскрину).         |
| `timeout`  | `number` *(опц.)*          | Через скільки мс зупинити спостереження. **Якщо не передати — спостерігач живе до анмаунту.**  |

## Return

| Params        | Type         | Description                          |
| ------------- | ------------ | ------------------------------------ |
| `startObserve`| `() => void` | Запустити спостереження.             |
| `stopObserve` | `() => void` | Зупинити спостереження вручну.       |

## Як працює

`startObserve` вішає `ResizeObserver` на `target`; кожен тік викликає `callback`, якщо не
триває viewport-перехід фуллскрину (гард `isViewportTransition`, вікно 1000 мс). Якщо переданий
`timeout` — через нього `stopObserve` сам відключить спостерігача. На анмаунті все чиститься.

> **Практичне правило:** майже завжди передавайте `timeout`. Інстанція без таймауту живе до
> `onUnmounted` і може зловити ресайз тоді, коли скрол уже не треба чіпати — саме це давало баг
> із фуллскрином (див. [п.4](./Readme.md#pitfall-fullscreen)).
